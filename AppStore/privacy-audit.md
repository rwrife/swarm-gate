# App Store privacy and permissions audit (2026-10-12)

App privacy label: **Data Not Collected**. Runs and settings stay on-device. No network use, accounts, cloud sync, ads, analytics, telemetry, third-party tracking SDKs, ATT prompt, advertising identifier, or health APIs.

Source check: `scripts/check_contract.py` rejects `Network`, `FoundationNetworking`, `WebKit`, `URLSession`, `NWConnection`, `WKWebView`; `toolchain.json` network allowlist is empty. Source imports: app uses SwiftUI, SpriteKit, UIKit, SwarmGateKit, SwarmGateStore; engine uses Swift stdlib/Foundation; store uses GRDB/SQLite locally. Neither app nor package source has an external HTTP endpoint. `Info.plist` is Xcode-generated; configured keys: `CFBundleDisplayName=SwarmGate`, `UILaunchScreen_Generation=YES`, `CFBundleIdentifier=com.infinityball.swarmgate`, `UIDeviceFamily=[1]` from `TARGETED_DEVICE_FAMILY=1`, app icon from `ASSETCATALOG_COMPILER_APPICON_NAME=AppIcon`. No `NS*UsageDescription` permission keys or unused entitlements configured. CI inspects built and archived Info.plists and fails if target family or bundle ID drift.

Listing copy reviewed against implemented UI in `SwarmGate/App` and merged engine/store packages. Removed claims for shareable seed codes, in-app CSV/JSON backup/export, curses disguised as gifts, boss health bars, and constant friend-matching waves: these were not shipped UI contracts. SQLite supports backup/CSV internally, but no in-app controls expose them. No TestFlight or device privacy evidence claimed here; release issue #7 supplies that evidence.

Artwork: `AppStore/icon.png` generated via `spark-media` OpenAI Images API, model `gpt-image-2.5-flare`, high quality, 1024x1024 opaque PNG (RGB). Prompt began with issue #6's verbatim brief, then added actual game context: portrait one-thumb zombie-wave lane defense, glowing gate, stylized abstract swarm columns, power-up sparks, bomb burst, neon lime/teal over deep-purple gradient, no gore/text/watermark/frame. Visual inspection of text/symbol content not automated; CI validates archive `Assets.car` and `AppIcon*.png` rasters.
